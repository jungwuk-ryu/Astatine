# Agent Instructions

## Commit Policy

- When a task is complete, create an atomic Conventional Commit for that completed task.
- Keep commits scoped to one logical change. Do not combine unrelated fixes, generated output, or existing dirty work in the same commit.
- Stage only files that belong to the completed task; leave unrelated local changes untouched.
- Use Conventional Commit messages such as `fix:`, `feat:`, `docs:`, `test:`, `refactor:`, or `chore:`.
